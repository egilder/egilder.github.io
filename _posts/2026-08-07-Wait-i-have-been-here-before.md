Over the years I have started many projects only to either completely abandon them or wipe everything and start over. With Microsoft continuing the [platform decay](https://en.wikipedia.org/wiki/Enshittification) of the Windows Operating System I have yet _again_ installed another Linux OS. Just like my previous post [So I did a thing...](https://egilder.github.io/blog/so-i-did-a-thing/) the Linux distribution is based on [Arch Linux](https://archlinux.org/) called [CachyOS](https://cachyos.org/). You can do everything on CachyOS that you do on Arch Linux with the added benefit of it having an overall more "user" friendly experience.

I chose to install it with the GUI Installer opting to go with the default KDE Plasma desktop environment. In my previous Arch OS install I was going to use the i3 desktop environment but chose to go a more balanced route. The installer was very simple to run through and after a reboot everything was up and running with very minimal fuss. I did encounter an issue where the previous install of Windows OS wasn't being erased during the GUI Installer prompts. The issues were easily solved while still on the bootable USB by just running the KDE Partition Manager and deleting the old partitions and re-running the installer.

Linux continues to be one of the OS's that I fall back to due to the superior customizability that it offers. Couple that with the fact that CachyOS just worked right out of the box I think this time I will not be going back to Windows any time soon (at least until Tax Season).
